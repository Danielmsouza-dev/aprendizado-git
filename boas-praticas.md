# Boas práticas de Git e GitHub

1. **Crie branches para mudanças específicas:** mantenha a `main` estável e trabalhe em branches com nomes claros, como `feature/nova-funcionalidade` ou `fix/correcao-login`.
2. **Faça commits pequenos e descritivos:** cada commit deve registrar uma mudança coerente, com uma mensagem que explique o que foi feito.
3. **Sincronize sua branch com frequência:** atualize-a em relação à `main` para reduzir conflitos e identificar problemas cedo.
4. **Revise as mudanças em Pull Requests:** descreva o objetivo, confira o diff e peça revisão antes de integrar alterações importantes.
5. **Não versione segredos:** mantenha senhas, tokens e chaves fora do repositório; use variáveis de ambiente e arquivos ignorados pelo Git.
